# Placa

> Signage on drawing paper

A standalone design reference for **Placa**, one of ten designs built for
MarvinRouter. This repo holds the complete token set, the identity rules that
tokens cannot express, and a component gallery that renders every part of the
system.

Open `index.html` — there is no build step.

---

## Where it comes from

Brazilian road and wayfinding signage: amber signal paint on light grey drawing paper, chunky borders, and offset shadows that read like a painted board rather than a page.

## Palette

Amber (#f2a007) is the only saturated colour and it is reserved for a signal or a primary action. Everything else is a grey-green paper ramp, so a screen full of tables still points at one thing.

Core roles in this design:

| Token | Value | Role |
| --- | --- | --- |
| `--paper` | `#e7ebe6` | Page ground |
| `--sheet` | `#f3f5f1` | Raised surfaces |
| `--ink` | `#142029` | Primary text |
| `--ink-2` | `#4b5a63` | Secondary text |
| `--ink-3` | `#75847f` | Muted text and labels |
| `--rule` | `#c2cbc4` | Borders and dividers |
| `--signal` | `#f2a007` | Action and focus |
| `--board` | `#142029` | Code and inverted panels |

The design is 66 tokens. 13 further values are *derived*
from them for contrast and noted as such in `theme.css` and at the end of the
gallery. `theme.css` is the source of truth and the gallery prints every one.

## Typography

Overpass for text and Overpass Mono for numbers: both were drawn for signage and hold up at small sizes and low resolution. Headings run at 800 with tight negative tracking.

Fonts shipped in this repo: Overpass, Overpass Mono. Each is a latin subset in
`fonts/`, declared with `@font-face` and `font-display: swap` so the page never
blocks on a webfont. They are redistributed under the SIL Open Font License
1.1; see `fonts/LICENSE.txt` for the copyright notices.

| Token | Value |
| --- | --- |
| `--font` | `"Overpass", system-ui, -apple-system, "Segoe UI", sans-serif` |
| `--mono` | `"Overpass Mono", ui-monospace, "Cascadia Mono", monospace` |
| `--display` | `var(--font)` |
| `--display-weight` | `800` |

## Shape and depth

10px radii on controls, 2px borders, and a hard 6px 6px 0 shadow. Depth comes from an offset, never from a blur.

## Accessibility

Amber on paper sits near 2.1:1, so it is never used for text — only for borders, fills behind dark text, and the accent rule. Body text is --ink on --paper at roughly 13:1.

Where the designer's colour could not carry text, this repo ships a derived
value rather than changing the palette:

| Token | Chosen | Derived for text | Why |
| --- | --- | --- | --- |
| `--signal` | `#f2a007` | `--signal-text` `#905f04` | The raw signal is only 1.78:1 on this paper, unreadable as text. |
| `--ink-3` | `#75847f` | `--ink-3-text` `#5b6662` | Muted labels sit on panels as well as the page. |
| `--add` / `--del` | `#1d7a4e` / `#b23a3a` | `--add-text` / `--del-text` | Success and error text must clear 4.5:1 on a tinted badge. |
| `--code-str` | `#6b4a00` | `--board-key-text` | Code keys are small and often on a diff tint. |
| focus ring | — | `--focus-ring` `#b77905` | A ring has to be visible on page *and* panel. |

Every derived value is generated by pushing the original colour toward the
opposite end of the ramp until it clears its floor, so it stays as close to the
designer's intent as the contrast minimum allows.

### Conventions this design keeps

- **Status is never colour alone.** Every badge pairs its colour with a word, and
  a dot is always accompanied by a label.
- **Focus is always visible.** `:focus-visible` draws a 3px `--focus-ring` ring
  with a 2px offset, on every interactive element.
- **Targets are at least 44px tall** for primary controls and 34px for small ones
  used inside dense areas.
- **Progress carries its value in text**, not only in the width of a bar.
- **One `h1` per page and no skipped heading levels** — the gallery is checked
  for both.
- **Motion respects `prefers-reduced-motion`** — transitions collapse to
  effectively zero rather than disappearing, so state changes stay legible.

## Files

```
index.html   component gallery — every component, this design
design.css   component styles, written against tokens only
theme.css    the 66 design tokens
fonts.css    @font-face declarations
fonts/       latin-subset woff2 files
```

`design.css` contains no colour, radius or font literal. That is deliberate: the
file is shared across all ten designs, and only `theme.css` differs.

## Using it elsewhere

Copy `theme.css` and set `data-theme="placa"` on your root element. The
tokens are namespaced by attribute, so this file can sit alongside another design
in the same page.
